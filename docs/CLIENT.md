# 完整牌局客户端

H2 使用服务端可见快照渲染大厅、准备室、夜间行动、发言、公投、遗言、猎人与结算。客户端不生成身份、死亡、票型或胜负；原型中的假转写和本地阶段推进已移除。

## 模块

- core：标签页 sessionStorage、纯视图模型、绝对截止时间和中文角色提示。
- api：同源 JSON、Bearer、幂等请求、fetch SSE、cursor 与重连。
- voice：用户点击授权后的 MediaRecorder、录音清理、Blob 哈希与播放 URL 回收。
- view：白名单文本转义、事件委托、键盘焦点、响应式布局和持久错误反馈。
- app：协调快照、用户意图、可选语音/复盘接口，不在本地判定规则。
- 根 app.js：只构造浏览器依赖并启动；本身也纳入测试。

房间码现在是随机 8 位十六进制显示串（WY 前缀），可以复制和凭码加入；座位令牌不进入 URL、DOM 或跨标签 localStorage。

## 验证边界

37 个客户端测试验证角色/阶段分支、实际请求构造、幂等重试、SSE 分块与恢复、录音拒绝/异常、哈希不匹配、退出清理及 DOM 事件。每个执行文件的行、函数和分支覆盖率均不低于 95%。

Node 依赖注入和 Fake DOM 验证逻辑，不能替代真实 Chrome 的渲染、麦克风与 WebRTC。真实浏览器验收作为后续 CI 一并运行并单独报告。

本阶段保留语音与复盘的客户端入口，服务端能力由后续功能 PR 接入；端点不可用时显示真实失败，不模拟成功。只有明确开启实时或开始录音时才会请求麦克风。
