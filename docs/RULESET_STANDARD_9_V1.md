# standard-9-v1 规则规范

本文件是雾隐镇首个可玩版本的权威规则基线。实现和测试不得依赖未在本文件中定义的口头规则。

## 角色配置

| 阵营 | 角色 | 数量 |
| --- | --- | ---: |
| 狼人 | 狼人 | 3 |
| 好人 | 预言家 | 1 |
| 好人 | 女巫 | 1 |
| 好人 | 猎人 | 1 |
| 好人 | 平民 | 3 |

首版不设警长、第三方阵营和额外角色。角色在开局时一次性随机分配并写入权威事件，事件重放不得重新随机。

## 阶段顺序

```text
LOBBY
  -> ROLE_REVEAL
  -> NIGHT_WOLF
  -> NIGHT_WITCH
  -> NIGHT_SEER
  -> DAWN_RESOLUTION
  -> DAY_SPEECH
  -> DAY_VOTE
  -> HUNTER_SHOT（按条件进入）
  -> GAME_OVER 或下一轮 NIGHT_WOLF
```

夜间行动先记录意图，在 `DAWN_RESOLUTION` 一次性计算死亡集合。任何角色提交夜间行动时都不得提前修改玩家存活状态。

## 狼人

- 仅存活狼人可以提交夜间目标。
- 狼人只能选择存活且非自己的玩家。
- 每名狼人每晚最多提交一次，允许在阶段截止前修改自己的选择。
- 获得严格多数票的目标被袭击。
- 最高票平票或没有目标获得严格多数时，当夜无人被狼人袭击。
- 超时未提交等同于弃权。

## 女巫

- 女巫在自己的夜间阶段知道狼人当夜形成的袭击目标。
- 解药和毒药各一瓶，整局各最多使用一次。
- 女巫首夜可以自救，之后不能自救。
- 同一夜不能同时使用解药和毒药。
- 毒药只能选择存活且不是女巫自己的玩家。
- 被毒药杀死的猎人不能开枪。
- 超时未提交等同于不使用药物。

## 预言家

- 每晚可以查验一名存活且不是自己的玩家。
- 查验结果只有预言家本人可见，结果只包含狼人或好人阵营。
- 每晚最多形成一个最终查验结果。
- 超时未提交则当夜没有查验结果。

## 猎人

- 猎人被狼人袭击或白天放逐时进入 `HUNTER_SHOT`。
- 猎人被女巫毒杀时不能开枪。
- 猎人可以选择一名其他存活玩家，也可以放弃开枪。
- 猎人行动完成或超时后，系统再统一判断胜负。
- 超时未提交等同于放弃开枪。

## 白天发言与公投

- 首版不设警长和警徽流。
- 存活玩家按席位顺序获得发言权。
- 发言内容不参与规则自动判定。
- 每名存活玩家拥有一票，可以投给其他存活玩家或弃票。
- 阶段截止时最后一次合法选择为最终投票。
- 唯一最高票玩家被放逐。
- 最高票平票时无人被放逐，不进行 PK 或二次投票。
- 死亡玩家没有投票权。
- 白天被放逐的玩家拥有一次遗言；夜间死亡玩家首版没有遗言。

## 身份公开

- 对局进行中，死亡和放逐只公开席位与死亡原因，不公开角色。
- 对局结束后一次性公开全部角色和允许复盘的行动结果。
- 普通出局玩家不会因为死亡自动获得全部身份视图。

## 胜负判定

胜负只在当前结算批次和待处理猎人行动全部完成后判断：

1. 存活狼人数量为 0，好人获胜。
2. 否则，存活狼人数量大于或等于存活非狼人数量，狼人获胜。
3. 其他情况进入下一轮。

如果猎人击杀最后一名狼人，即使猎人开枪前狼人已达到人数优势，也必须等待开枪结算后判定好人获胜。

## 超时与断线

- 超时采用各角色章节定义的跳过或弃权行为。
- 断线不会改变角色、存活状态或已提交的最终行动。
- 重连后恢复本人有权查看的最新快照。
- 首版不允许 AI 在断线后读取其他玩家私密信息。

## 不变量

- 恰好 9 个唯一席位和 9 个唯一角色分配。
- 角色数量始终为 3 狼人、1 预言家、1 女巫、1 猎人、3 平民。
- 事件序号严格递增。
- 死亡玩家不会恢复存活。
- 药物余量只能是 0 或 1。
- 每个阶段只接受该阶段允许的命令。
- 任何客户端快照都不得包含当前查看者无权看到的角色或行动。
